# Third-party software and assets

VoidLoop's own code and story are © 2026 BitJacker (see `LICENSE`). The downloadable builds
(Windows `.exe`/`.msi`, Linux `.tar.gz`/`.deb`/`.AppImage`) also contain the following third-party components,
each under its own licence:

| Component | Licence | Notes |
|-----------|---------|-------|
| [Python](https://www.python.org/) | PSF License | The interpreter is embedded by PyInstaller. |
| [pygame](https://www.pygame.org/) | LGPL-2.1 | Shipped as separate files (never statically linked), so it can be replaced. |
| [SDL2](https://libsdl.org/), SDL_image, SDL_mixer, SDL_ttf | zlib | Bundled with pygame in the `pygame.libs` folder. |
| FreeType, libpng, libjpeg-turbo, zlib and other libraries bundled with the pygame wheel | FTL / BSD-style / zlib | See the pygame wheel for their licence texts. |
| [PyInstaller](https://pyinstaller.org/) bootloader | GPL-2.0 with the bootloader exception | Used to create the executables; the exception allows distributing the result under any licence. |
| [Orbitron](https://github.com/theleagueof/orbitron) (Black, Bold) | SIL Open Font License 1.1 | © The Orbitron Project Authors. Licence text: `VoidLoop/assets/fonts/OFL-Orbitron.txt`. |
| [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono) | SIL Open Font License 1.1 | © Carrois Type Design. Licence text: `VoidLoop/assets/fonts/OFL-ShareTechMono.txt`. |

The fonts were converted from WOFF2 to TrueType without altering the glyph outlines. All music, sound effects,
graphics and icons are generated by the game's own code at run time (or by `tools/make_icons.py`); no other
third-party media is included.
